# Changesets

This folder holds pending release notes for tickdeck packages, managed by [Changesets](https://github.com/changesets/changesets).

Run `pnpm changeset` in the repository root, pick the packages your change affects and the semver bump for each, and write a one-line summary for users. Commit the generated Markdown file with your change. Maintainers turn pending changesets into version bumps and changelog entries at release time.
