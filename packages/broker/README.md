# @tickdeck/broker

The broker adapter contract (commands out, updates in), order and position tracking, acknowledgement deadlines and a mock broker for development and tests.

> Pre-alpha and under construction. APIs will change without notice.

## Install

```sh
npm install @tickdeck/broker
```

Part of [tickdeck](https://github.com/yakenator/tickdeck). Licensed under Apache-2.0.
