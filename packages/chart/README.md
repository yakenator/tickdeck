# @tickdeck/chart

Chart model, series styles, price scale modes and panes. Wraps the tickdeck rendering engine so the rest of the library never talks to it directly.

> Pre-alpha and under construction. APIs will change without notice.

## Install

```sh
npm install @tickdeck/chart
```

Part of [tickdeck](https://github.com/yakenator/tickdeck). Licensed under Apache-2.0.
