# @tickdeck/datafeed

The contract a host application implements to supply instruments, historical bars, live bars, quotes and order book depth, plus reference HTTP polling and WebSocket adapters.

> Pre-alpha and under construction. APIs will change without notice.

## Install

```sh
npm install @tickdeck/datafeed
```

Part of [tickdeck](https://github.com/yakenator/tickdeck). Licensed under Apache-2.0.
