# @tickdeck/react

React components wrapping the tickdeck Web Components. Supports React 18 and 19.

> Pre-alpha and under construction. APIs will change without notice.

## Install

```sh
npm install @tickdeck/react
```

## Usage

```tsx
import { TdkPlaceholder } from '@tickdeck/react';

export const App = () => <TdkPlaceholder label="Hello" />;
```
