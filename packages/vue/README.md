# @tickdeck/vue

Vue 3 components wrapping the tickdeck Web Components.

> Pre-alpha and under construction. APIs will change without notice.

## Install

```sh
npm install @tickdeck/vue
```

## Usage

```vue
<script setup lang="ts">
import { TdkPlaceholder } from '@tickdeck/vue';
</script>

<template>
  <TdkPlaceholder label="Hello" />
</template>
```
