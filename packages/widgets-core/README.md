# @tickdeck/widgets-core

Headless controllers behind every tickdeck widget: state, validation, derived values and commands, with no DOM access. Use them directly to build a fully custom UI.

> Pre-alpha and under construction. APIs will change without notice.

## Install

```sh
npm install @tickdeck/widgets-core
```

Part of [tickdeck](https://github.com/yakenator/tickdeck). Licensed under Apache-2.0.
