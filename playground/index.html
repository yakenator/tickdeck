tickdeck playground 0.1.0-alpha.1

Every way to adopt tickdeck, each in a small app that installs the published packages from the public npm registry at one pinned version, exactly as an external project would. Each release is checked here: install, build, type check, Node tests and a browser run that places a limit order with take-profit and stop-loss, fills it and closes it at the take-profit. Everything runs on MockFeed and MockBroker, so no market data or broker account is needed.

Ways to adopt tickdeck

CDN, no build step

One ES module from jsDelivr registers the tdk-* elements and exports every API. A static HTML page is all you need: the chart, order ticket, trade buttons, account panel and notifications on one mock session. 

<script type="module" src="https://cdn.jsdelivr.net/npm/@tickdeck/all@0.1.0-alpha.1/dist/tickdeck.js"></script>
<tdk-order-ticket instrument="MOCK:ACME" kind="limit"></tdk-order-ticket>
<script type="module">
  import { BrokerSession, MockBroker, MockFeed } from 'https://cdn.jsdelivr.net/npm/@tickdeck/all@0.1.0-alpha.1/dist/tickdeck.js';
  const feed = new MockFeed();
  const session = new BrokerSession(new MockBroker({ feed }));
  await session.start();
  Object.assign(document.querySelector('tdk-order-ticket'), { session, feed });
</script>

Web Components with a bundler

The tdk-* custom elements and the chart from npm, bundled with Vite and no framework. This is the full trading screen: instrument, timeframe, style, scale and theme switchers, Alt-click a chart price into the ticket, Modify from the panel, and a take-profit and stop-loss dialog. 

npm install @tickdeck/elements@0.1.0-alpha.1 @tickdeck/chart@0.1.0-alpha.1 @tickdeck/broker@0.1.0-alpha.1 @tickdeck/datafeed@0.1.0-alpha.1

import '@tickdeck/elements/define';
import { attachTrading, createChartView } from '@tickdeck/chart';
import { BrokerSession, MockBroker } from '@tickdeck/broker';
import { MockFeed } from '@tickdeck/datafeed';

const feed = new MockFeed();
const session = new BrokerSession(new MockBroker({ feed }));
await session.start();
attachTrading(createChartView(chart, { feed, instrument: 'MOCK:ACME', timeframe: '1m' }), session);
Object.assign(ticket, { session, feed });

React

@tickdeck/react wraps each element as a React 19 component: rich props become element properties, callbacks such as onAmend subscribe to its events, and refs reach the element. The chart is created in an effect and disposed on unmount. 

npm install @tickdeck/react@0.1.0-alpha.1 @tickdeck/elements@0.1.0-alpha.1 @tickdeck/chart@0.1.0-alpha.1 @tickdeck/broker@0.1.0-alpha.1 @tickdeck/datafeed@0.1.0-alpha.1

<TdkOrderTicket ref={ticket} session={session} feed={feed} instrument="MOCK:ACME" kind="limit" />
<TdkAccountPanel session={session} feed={feed}
  onAmend={(event) => ticket.current?.amend(event.detail.order)} />

useEffect(() => {
  const view = createChartView(container.current!, { feed, instrument, timeframe: '1m' });
  attachTrading(view, session);
  return () => view.dispose();
}, []);

Vue

@tickdeck/vue wraps each element as a Vue 3 component with props, emits such as @amend and the element exposed on the component instance. The chart is created in onMounted and disposed before unmount. 

npm install @tickdeck/vue@0.1.0-alpha.1 @tickdeck/elements@0.1.0-alpha.1 @tickdeck/chart@0.1.0-alpha.1 @tickdeck/broker@0.1.0-alpha.1 @tickdeck/datafeed@0.1.0-alpha.1

<TdkOrderTicket ref="ticket" :session="session" :feed="feed" instrument="MOCK:ACME" kind="limit" />
<TdkAccountPanel :session="session" :feed="feed"
  @amend="({ order }) => ticket?.element?.amend(order)" />

onMounted(() => {
  view = createChartView(chart.value!, { feed, instrument: 'MOCK:ACME', timeframe: '1m' });
  attachTrading(view, session);
});

Headless in Node

The logic layer needs no DOM. A strategy script places a bracket order on MockBroker, moves the MockFeed market to fill it and to hit the take-profit, and prints the fills and P&L. A second script imports @tickdeck/chart, elements and all in Node and renders the React and Vue wrappers on the server. 

npm install @tickdeck/broker@0.1.0-alpha.1 @tickdeck/datafeed@0.1.0-alpha.1 @tickdeck/core@0.1.0-alpha.1

const feed = new MockFeed({ autoTick: false });
const session = new BrokerSession(new MockBroker({ feed }));
await session.start();
await session.submitOrder({ instrument: 'MOCK:ACME', side: 'buy', kind: 'limit',
  quantity: 10, limitPrice: 99.5, takeProfit: 101, stopLoss: 99 });
await feed.setQuote('MOCK:ACME', { bid: 99.47, ask: 99.49 }); // fills the entry

TypeScript

A consumer that touches every package, a custom BrokerConnector included, type-checks with moduleResolution bundler, nodenext and node16, with skipLibCheck off so the published declarations are checked too. 

{
  "compilerOptions": {
    "module": "NodeNext",
    "moduleResolution": "NodeNext",
    "lib": ["ES2022", "DOM", "DOM.Iterable"],
    "strict": true,
    "skipLibCheck": false
  }
}
